Open a suite report by run id

The backend can fetch a single test-suite run by id, but it has no list endpoint for them, so this UI cannot enumerate them. Paste the id returned when you ran a suite.

Missing backend capability: GET /api/scenario-scans and GET /api/authentication-scans list endpoints. See docs/UI.md for the proposed contracts.

What the reports contain

  • Fixture report: verdict, reason, remediation, setup gates, two-part evidence, the decision checklist, per-check results and constraint counters.
  • Section view: the backend's nine-section projection, which is a bounded fixture projection and not yet the complete P0 report contract.
  • Suite reports: scenario or authentication transcript results with the same constraints and limitations the run recorded.
  • Every report states its mode. Nothing here is live-target evidence.
