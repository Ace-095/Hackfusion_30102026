How to read this table

  • Expected access is the backend's classification: public, authenticated, role:<name>, owner-only or unknown. unknown is a valid answer and can never become a CONFIRMED verdict.
  • Provenance is the source of that expectation. OpenAPI security expresses authentication requirements, not authorization policy, so it is labelled as such. The fixture's owner-only rule comes from the synthetic fixture policy.
  • An uploaded specification is inspected in memory only. It never changes this inventory, never selects a target and is never scanned.
