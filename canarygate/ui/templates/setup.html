Why readiness is a hard gate

  • Authentication — without two working identities there is no "other account" to test from; checks become SKIPPED, not passed.
  • Resource — a private resource per account is needed so a cross-account read has something to target.
  • Ownership — the backend must prove who owns the resource before it may claim a cross-user disclosure. An ID alone is not proof.
  • When a gate fails the backend reports PARTIAL, FAILED, SKIPPED or NEEDS_MANUAL_INPUT with a reason. This UI never upgrades those states.
