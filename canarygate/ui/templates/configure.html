{{ icon("lock") }} Enforced for every request

  • Exact host and port only — no wildcard, no redirects, no external traffic.
  • Only operations listed in the scope file with the exact query string pass.
  • DELETE is always blocked; PUT/PATCH are blocked by default.
  • Request budget and sequential execution are enforced before connection.
  • Requests and responses are size-limited; DNS is validated and pinned.
  • Credentials are read from the environment and redacted everywhere.

Source of truth: the backend scope loader and central guard. This page only describes them.

{{ icon("info") }} To make this page editable

  1. A validated configuration object in the backend (scope + recipe + spec), rejected if it violates the safety rules.
  2. A POST /api/scan-jobs contract that accepts it and returns a job id.
  3. A written authorization decision for every new target — the guard cannot infer permission from a form.
  4. Then this form becomes live and the disabled controls are removed.
