{{ icon("info") }} What the browser is allowed to do

  • The forms submit only a port. They cannot choose a host, path, account, credential or expected result; the backend's request model rejects extra fields.
  • The scope, credentials and plan are built by the backend. The lab's passwords, tokens and private markers are never sent to the browser.
  • A refusal is shown as a refusal: HTTP 400 for a bad configuration, 502 when the lab is unreachable, and no evidence is stored in either case.
  • Run ids above are links to the stored evidence, the section report and the backend's own HTML report.
