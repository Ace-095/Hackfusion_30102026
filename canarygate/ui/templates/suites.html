{{ icon("key") }} Authentication scenarios

POST /api/authentication-scans

Runs the eight P0 authentication checks (AUTHN-01 … AUTHN-08) for one token transcript. Inapplicable checks are reported as SKIPPED with a reason.

Titles are the backend's own scenario titles, not predicted outcomes.

{{ icon("info") }} What a suite run demonstrates

  • Read-BOLA — the decision path that turns ownership proof and private-data disclosure into a verdict, including honest non-CONFIRMED outcomes.
  • Authentication — missing, malformed, wrong-scheme, crafted-JWT and API-key probes, with the effective-identity change required before a probe can be CONFIRMED.
  • Every run records request counters and limits the backend applied.
