Test suites

Bundled, deterministic offline transcripts. They exercise the guarded pipeline without any network transport: the scope, accounts and responses are synthetic recordings bundled with the backend.

These are recorded scenarios, not live tests. Each run reports transport=offline_transcript and network_transport_enabled=false. They demonstrate the decision logic; they do not prove anything about a real API.

Read-BOLA scenarios

POST /api/scenario-scans

Runs the full read-BOLA decision path for one transcript: ownership evidence, disclosure evidence, the ten-key checklist and a verdict.

Scenario ids come from the backend registry; this page does not invent or rename them.

Authentication scenarios

POST /api/authentication-scans

Runs the eight P0 authentication checks (AUTHN-01 … AUTHN-08) for one token transcript. Inapplicable checks are reported as SKIPPED with a reason.

Open a previous suite run

Suite runs persist in the local database, but the backend has no list endpoint for them yet, so this UI cannot enumerate past runs. Use the run id it returned.
