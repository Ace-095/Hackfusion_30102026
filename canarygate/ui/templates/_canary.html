{# ========================================================================== The canary. Hand-drawn SVG, no image files, no icon library. Why a canary: the whole product is named after one. In a mine the bird reacts to gas long before a person can, and when it goes quiet that silence is itself the signal. CanaryGate borrows exactly that idea for API authorisation — the earlier the warning, the cheaper the fix. Every part is a separate group so the stylesheet can animate beak, wing, tail and eye independently. The bird is decorative: the sentence beside it carries the meaning, so screen readers are not read a description of a drawing. ========================================================================== #} {% macro canary(size="md", state="singing", cls="", uid="bird") -%} {#- ``uid`` keeps the gradient ids unique when the macro is used more than once in a document: duplicate ids are invalid HTML and the second reference silently resolves to the first. -#} {%- endmacro %} {# --------------------------------------------------------------------------- The burst: celebration particles for the verdict reveal.
