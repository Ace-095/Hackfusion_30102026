Spec inspection

Parses an OpenAPI 3.0/3.1 document in memory and shows the endpoint inventory with expected access and provenance. Inspection only: nothing is saved, no target is selected and no scan is started.

Bounded parser. This is not full OpenAPI validation. It requires a paths mapping, resolves local $ref pointers only, rejects remote references, merge keys and duplicate keys, and limits input to 128 KiB of UTF-8.

Why uploads are separate from scans

  • The fixture scanner in this build is bound to the bundled synthetic fixture. It cannot be pointed at an uploaded specification.
  • Uploaded documents are not persisted, so they cannot become stored evidence.
  • The response echoes parameter details from the document; that is not a production secret-redaction system.
  • Connecting an uploaded specification to a live scan requires the guarded runner, a written scope and organizer authorization. That is not implemented.
